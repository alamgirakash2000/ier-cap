# Fonts

`lmroman8-regular.otf`, `lmroman8-italic.otf` and `lmroman8-bold.otf` are Latin Modern Roman, unmodified from the `lm` package on CTAN (https://ctan.org/pkg/lm). They are distributed under the GUST Font License, a copy of which is in `GUST-FONT-LICENSE.TXT`.

`paper/style.py` registers them with matplotlib, so the figure text matches the paper on any machine.
